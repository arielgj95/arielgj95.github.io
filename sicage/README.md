# SICAGE project page

Static project page for **SICAGE: Speaker-Independent Culture-Aware Gesture Generation using TED4C-L Dataset**.

- Live page: <https://arielgj95.github.io/sicage/>
- Code: <https://github.com/arielgj95/SICAGE>
- Dataset: <https://huggingface.co/datasets/ariel-95/TED4C-L>

The page follows the academic-project structure of [`paper-website/paper-website.github.io`](https://github.com/paper-website/paper-website.github.io) while using a small dependency-free implementation. The arXiv control is intentionally marked as coming soon.

Comparison clips were generated by the SICAGE qualitative comparison pipeline. The pipeline figure is maintained in the SICAGE repository.
