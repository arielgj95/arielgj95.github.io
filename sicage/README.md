# SICAGE project page

Static project page for **SICAGE: Speaker-Independent Culture-Aware Gesture Generation using TED4C-L Dataset**, accepted at ECCV 2026 by Ariel Gjaci, Antonio Sgorbissa, and Vittorio Murino.

- Live page: <https://arielgj95.github.io/sicage/>
- Paper: <https://arxiv.org/abs/2606.30001>
- Code: <https://github.com/arielgj95/SICAGE>
- Dataset: <https://huggingface.co/datasets/ariel-95/TED4C-L>

The page follows the academic-project structure of [`paper-website/paper-website.github.io`](https://github.com/paper-website/paper-website.github.io) while using a small dependency-free implementation.

Comparison clips are the four videos from the ECCV supplementary `SICAGE_videos/` folder. The pipeline figure uses the transparent `SICAGE-V4` model image from the SICAGE repository.
